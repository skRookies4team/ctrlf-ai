# Canva PPT 제작 가이드

> Canva에서 바로 따라 만들 수 있는 단계별 가이드

---

## 시작하기

### Step 1: Canva 접속
1. [canva.com](https://www.canva.com) 접속
2. 로그인 (무료 계정 OK)

### Step 2: 새 프레젠테이션 생성
1. **"프레젠테이션"** 클릭
2. **"프레젠테이션 (16:9)"** 선택
3. 빈 템플릿으로 시작

### Step 3: 브랜드 키트 설정
왼쪽 메뉴 **"브랜드 키트"**에서 아래 색상 추가:
```
#6C5CE7  메인 보라
#A29BFE  연보라
#FDA7DF  핑크
#00D2D3  민트
#2D3436  다크그레이
```

---

## 슬라이드별 제작

### 슬라이드 1: 타이틀

**배경**:
- 그라데이션: `#6C5CE7` → `#A29BFE`
- Canva 검색: "retro game" 이미지 (투명도 20%)

**텍스트**:
```
"AI도 키울 수 있다면?"  (72pt, ExtraBold, 흰색)
"── AI 메이커 ──"       (32pt, Regular, 흰색 80%)
팀 이름 | 날짜          (18pt, Light, 흰색 60%)
```

---

### 슬라이드 4: 레벨 시스템 (핵심)

**세로 타임라인 만들기**:
1. 세로 선 배치 (4px, #E0E0E0)
2. 레벨 카드 6개 복사-붙여넣기

| 레벨 | 아이콘 | 색상 | 대사 |
|------|-------|------|------|
| Lv.1 | 👒 | `#FD79A8` | "사규가 뭐예요?" |
| Lv.2 | 🧒 | `#FDCB6E` | "출장비 규정 말씀이시군요" |
| Lv.3 | 🎓 | `#00B894` | "제12조에 따르면..." ← NOW |
| Lv.4 | 👔 | `#0984E3` | "3가지를 정리해드릴게요" |
| Lv.5 | 🎩 | `#6C5CE7` | "비교 분석해드릴까요?" |
| Lv.6 | 👑 | `#E84393` | "개정 필요성을 제안드립니다" |

**현재 레벨 강조 (Lv.3)**:
- 왼쪽에 "NOW ▶▶▶" 텍스트
- 테두리: 3px solid `#00B894`

---

### 슬라이드 5: 품질 게이트

**3개 카드 (280x320px, 모서리 24px)**:

| 카드 | 배경 | 내용 |
|------|------|------|
| OK | `#00B894` | ✅ 😊 "자신있게 대답할게요" |
| LOW | `#FDCB6E` | ⚠️ 🤔 "확실치 않아요" |
| INSUFFICIENT | `#E17055` | ❌ 😅 "잘 모르겠어요" |

---

### 슬라이드 9: 성장 대시보드

**배경**: `#1A1A2E` (다크 모드)

**상단 스탯 카드 3개**:
```
[현재 레벨]     [품질 점수]    [총 피드백]
  Lv.3 🎓        78/100         3,247
  고등학생        ▲12           +127
```

**성장 그래프**: Canva 검색 "line chart"

**경험치 바**:
```
[다음 레벨까지]  ████████████░░░░ 78%
```

---

### 슬라이드 12: 마무리

**배경**: `#6C5CE7` → `#E84393` 그라데이션

**텍스트 (중앙, 순차 등장)**:
```
"오늘의 신입,"     (72pt)
"내일의 박사."     (80pt)

"그 성장의 주인공은"  (32pt)
"여러분입니다."      (48pt)

[같이 키우실 분? 🙋]  ← 버튼 스타일
```

## 애니메이션 설정

1. 요소 클릭 → 상단 **"애니메이션"**
2. 추천 효과:
   - 타이틀: Rise
   - 카드: Pop (순차)
   - 그래프: Wipe
   - 마무리: Typewriter

---

## 내보내기

1. **공유** → **다운로드**
2. 형식: **PPTX** 또는 **PDF**
3. 발표용: **프레젠테이션 링크** 생성
