## 슬라이드별 디자인

### 슬라이드 1: 타이틀
- **배경**: 보라→핑크 그라데이션 + 레트로 게임 픽셀 패턴
- **중앙**: "AI도 키울 수 있다면?" (72pt, 흰색)
- **하단**: 팀명, 날짜

### 슬라이드 2: 문제 제기
- **배경**: 밝은 회색 (#F8F9FA)
- **좌우 분할**: 일반 챗봇 (회색, 평평한 그래프) vs 사람 (초록, 우상향 그래프)
- **하단**: "왜 AI는 성장하지 못할까요?" (보라색)

### 슬라이드 3: 솔루션
- **배경**: 보라 그라데이션
- **중앙**: Ctrl+F AI 로고 (흰색 원형 배경)
- **성장 아이콘**: 🌱 → 🌿 → 🌳 → 🌲

### 슬라이드 4: 레벨 시스템 (핵심!)
- **배경**: 흰색
- **세로 타임라인**: Lv.1~6 순차 배치
- **현재 레벨 (Lv.3)**: "NOW" 표시 + 펄스 애니메이션
- **각 레벨**: 고유 색상 + 아이콘 + 대사 예시

### 슬라이드 5: 품질 게이트
- **배경**: 밝은 회색
- **3개 카드**: OK(초록), LOW(노랑), INSUFFICIENT(빨강)
- **각 카드**: 이모지 + 설명

### 슬라이드 6: 피드백 순환
- **원형 플로우**: 질문 → 답변 → 피드백 → 분석 → 튜닝 → (반복)
- **중앙**: "분기별 레벨업!"

### 슬라이드 7: 도메인 전문성
- **좌우 분할**: 레이더 차트 + 설명 텍스트
- **프린세스 메이커 비유**: 무술→전사, 학문→학자

### 슬라이드 8: 데모 화면
- **배경**: 보라 그라데이션
- **중앙**: 채팅 UI 목업 (피드백 버튼 강조)

### 슬라이드 9: 성장 대시보드
- **배경**: 다크 모드 (#1A1A2E)
- **상단**: 스탯 카드 3개 (레벨, 점수, 피드백 수)
- **중앙**: 성장 그래프 (우상향)
- **하단**: 경험치 바

### 슬라이드 10: 비교 표
- **좌우 카드**: 일반 챗봇 (회색) vs Ctrl+F AI (보라)
- **중앙**: VS 배지

### 슬라이드 11: 성장 일기
- **배경**: 베이지/크림색 종이 텍스처
- **일기장 프레임**: 손글씨 폰트로 성장 기록

### 슬라이드 12: 마무리
- **배경**: 보라→마젠타 그라데이션 + 파티클
- **중앙**: "오늘의 신입, 내일의 박사"
- **CTA**: "같이 키우실 분?"

### 슬라이드 13: 엔딩
- **배경**: 흰색
- **중앙**: 로고 + 슬로건 + 연락처 + QR코드
