```
PART 1. 도입 (2분)
├── 프린세스 메이커 향수 자극
```

- [ ] Canva에서 슬라이드 13장 제작

- [ ] 애니메이션 설정

- [ ] 라이브 데모 테스트 (3회 이상)
- [ ] 백업 영상 녹화
- [ ] 영상 자막 추가

- [ ] 1차: 대본 보면서 혼자 연습
- [ ] 2차: 팀원 앞에서 발표

- [ ] USB + 클라우드 백업

- [ ] 물 준비

| 질문 | 핵심 답변 |
