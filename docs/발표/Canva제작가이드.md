# Canva PPT 제작 가이드: AI 메이커

> Canva에서 바로 따라 만들 수 있는 단계별 가이드

---

## 시작하기

### Step 1: Canva 접속
1. [canva.com](https://www.canva.com) 접속
2. 로그인 (무료 계정 OK)

### Step 2: 새 프레젠테이션 생성
1. **"프레젠테이션"** 클릭
2. **"프레젠테이션 (16:9)"** 선택
3. 빈 템플릿으로 시작

### Step 3: 브랜드 키트 설정 (선택)
1. 왼쪽 메뉴 **"브랜드 키트"**
2. 아래 색상 추가:
   - `#6C5CE7` (메인 보라)
   - `#A29BFE` (연보라)
   - `#FDA7DF` (핑크)
   - `#00D2D3` (민트)
   - `#2D3436` (다크그레이)

## 슬라이드 1: 타이틀

### 배경 설정
1. 빈 슬라이드에서 **배경 클릭**
2. 왼쪽 **"배경"** 메뉴
3. **그라데이션** 선택
4. 색상: `#6C5CE7` → `#A29BFE` (좌→우)

### 요소 추가
1. **이미지 검색**: "retro game" 또는 "pixel art"
2. 이미지 삽입 후 **투명도 20%**로 설정
3. 전체 배경에 깔기

### 텍스트 추가
```
[제목]
폰트: Pretendard ExtraBold (없으면 Noto Sans KR Bold)
크기: 72pt
색상: #FFFFFF
내용: "AI도 키울 수 있다면?"

[부제]
폰트: Pretendard Regular
크기: 32pt
색상: #FFFFFF (투명도 80%)
내용: "── AI 메이커 ──"

[하단]
폰트: Pretendard Light
크기: 18pt
색상: #FFFFFF (투명도 60%)
내용: "팀 이름 | 2026.01.08"
```

### 배치
```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│      "AI도 키울 수 있다면?"          │  ← 중앙 상단 1/3
│                                     │
│          ── AI 메이커 ──            │  ← 중앙
│                                     │
│                                     │
│                                     │
│         팀 이름 | 2026.01.08        │  ← 하단 중앙
└─────────────────────────────────────┘
```

## 슬라이드 4: 성장 레벨 시스템 (핵심!)

### 배경
- 단색: `#FFFFFF`

### 제목
```
"AI의 성장 로드맵"

색상: #2D3436
위치: 상단 좌측
```

### 레벨 타임라인 만들기

**세로 라인**
1. **도형** → 선

4. 길이: 슬라이드 세로 70%

**레벨 카드 6개** (아래→위 순서로 배치)

각 카드 구조:
```
┌──────────────────────────────────────────────┐
│  [원형 아이콘]  Lv.X  레벨명   "대사 예시"    │
└──────────────────────────────────────────────┘
```

| 레벨 | 아이콘 | 이름 | 색상 | 대사 |
|------|-------|------|------|------|
| Lv.1 | 👒 | 초등학생 | `#FD79A8` | "사규가 뭐예요?" |
| Lv.2 | 🧒 | 중학생 | `#FDCB6E` | "아, 출장비 규정 말씀이시군요" |
| Lv.3 | 🎓 | 고등학생 | `#00B894` | "출장비 규정 제12조에 따르면..." |
| Lv.4 | 👔 | 대학생 | `#0984E3` | "관련 조항 3가지를 정리해드릴게요" |
| Lv.5 | 🎩 | 대학원생 | `#6C5CE7` | "유사 사례와 비교 분석해드릴까요?" |
| Lv.6 | 👑 | 박사 | `#E84393` | "이 규정의 개정 필요성을 제안드립니다" |

**현재 레벨 강조 (Lv.3)**
1. Lv.3 카드 왼쪽에 **"NOW ▶▶▶"** 텍스트
2. 색상: `#00B894`
3. 카드 테두리: 3px solid `#00B894`
4. **애니메이션**: 펄스 효과 (발표 모드에서)

### Canva 제작 순서
1. 세로 선 먼저 배치
2. 레벨 카드 6개 복사-붙여넣기
3. 각 카드 색상만 변경
4. Lv.3에 강조 효과
