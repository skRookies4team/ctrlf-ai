# CTRL+F AI 챗봇 - 발표 자료

## 1. 비즈니스 가치

### 1.1 문제 정의
**"정보 검색에 소요되는 시간이 업무 효율을 저하시킨다"**

| 통계 | 수치 | 출처 |
|------|------|------|
| 업무 시간 중 정보 검색 비율 | 20% (주당 약 9.3시간) | McKinsey Global Institute (2012) |
| 생성형 AI 도입 HR 리더 비율 | 38% | Gartner (2024) |
| AI 챗봇 자동 처리 가능 문의 비율 | 75% | HR Industry Report |
| 챗봇 vs 상담원 비용 차이 | $0.50 vs $6.00 (12배 절감) | IBM Watson |

### 1.2 솔루션
**사내 규정 전문 RAG 챗봇**
- 복잡한 규정 문서를 자연어로 즉시 검색
- 24시간 자동 응답으로 HR 부서 업무 부담 경감
- 출처 기반 답변으로 신뢰성 확보

### 1.3 기대 효과
- 직원 1인당 정보 검색 시간 절감
- HR 부서 반복 문의 응대 감소
- 규정 접근성 향상으로 컴플라이언스 강화

## 2. 기술적 차별화

### 2.1 일반 RAG vs CTRL+F AI 비교

| 구분 | 일반 RAG 챗봇 | CTRL+F AI |
|------|--------------|-----------|
| **검색 방식** | 단일 벡터 검색 | Query Expansion + RRF Fusion |
| **쿼리 처리** | 원본 쿼리만 사용 | 동의어/유사어 자동 확장 (20개 핵심 키워드) |
| **결과 병합** | 단순 점수 정렬 | Reciprocal Rank Fusion (다중 검색 결과 융합) |
| **환각 방지** | 없음 또는 기본 | 3중 안전장치 (Stats Fast Path, Privacy Gate, Low-relevance Gate) |
| **출처 표시** | 선택적 | 필수 (모든 답변에 근거 문서 명시) |

### 2.3 핵심 기술 상세

#### Query Expansion (쿼리 확장)
```
사용자 입력: "연차"
확장된 쿼리: "연차", "연차휴가", "유급휴가", "annual leave"
```
- 짧은 쿼리도 관련 문서를 놓치지 않음
- YAML 기반 확장 규칙으로 유지보수 용이

#### RRF Fusion (검색 결과 융합)
- 원본 쿼리 + 확장 쿼리 결과를 통합
- 순위 기반 점수로 다양한 관련 문서 상위 노출

#### 3중 안전장치
| 안전장치 | 기능 | 예시 |
|---------|------|------|
| Stats Fast Path | 통계 질문 차단 | "몇 명이 육아휴직 사용?" → 차단 |
| Privacy Query Gate | 개인정보 요청 차단 | "김철수 연락처 알려줘" → 차단 |
| Low-relevance Gate | 저품질 검색 결과 필터링 | 관련성 낮은 문서 제외 |

## 3. 성능 검증 (프로젝트 측정 데이터)

### 3.1 정상 응답률 개선
| 단계 | 정상 응답률 | 주요 개선 |
|------|------------|----------|
| 초기 버전 | 36% | 기준점 |
| 도메인 라우팅 적용 | 72% | 질문 유형별 최적화 |
| 환각 방지 강화 | 92% | 안전장치 도입 |
| 최종 버전 | **100%** | Query Expansion + RRF |

### 3.2 검색 품질 지표
| 지표 | 개선 전 | 개선 후 | 개선율 |
|------|----------|----------|--------|
| 평균 L2 Distance | 0.71 | **0.58** | 18% 향상 |
| 최고 품질 (L2 < 0.5) | 32% | **48%** | 50% 증가 |

### 3.3 Golden Query 테스트
- **25개 핵심 질문** 회귀 테스트 통과
- 모든 질문에서 정확한 출처 기반 답변 확인
- 안전장치 정상 작동 검증 완료

### 3.4 대규모 배치 테스트 (575개 질답 데이터셋)

#### LLM-as-a-Judge 품질 평가
GPT-4o를 평가자로 활용한 자동 품질 평가 시스템 구축

| 평가 항목 | 설명 | 척도 |
|----------|------|------|
| 정확성 (Accuracy) | 사실적으로 정확한가? | 1-5점 |
| 완전성 (Completeness) | 질문에 충분히 답했는가? | 1-5점 |
| 관련성 (Relevance) | 질문과 관련된 답변인가? | 1-5점 |
| 환각 (Hallucination) | 거짓 정보가 있는가? | Y/N |
| 종합 점수 (Overall) | 전체 품질 | 1-5점 |
