## 1. 메인 플로우 (End-to-End)

```mermaid
flowchart TD
    A[사용자 질문] --> B[요청 컨텍스트 초기화]
    B --> C{금지질문 필터}
    C -->|FORBIDDEN_BOTH| C1[차단 응답 반환]
    C -->|FORBIDDEN_RAG| C2[RAG 스킵 플래그]
    C -->|FORBIDDEN_BACKEND| C3[Backend 스킵 플래그]
    C -->|ALLOWED| D[PII 마스킹 INPUT]
    C2 --> D
    C3 --> D

    D --> E{Privacy Query Gate}
    E -->|명단 요청 감지| E1[차단 응답 반환]
    E -->|허용| F[라우팅 오케스트레이션]

    F --> G[Rule Router]
    G --> H{confidence >= 0.85?}
    H -->|YES| I[Rule 결과 확정]
    H -->|NO| J[LLM Router]
    J --> I

    I --> K{needs_clarify?}
    K -->|YES| K1[되묻기 응답]
    K -->|NO| L{requires_confirmation?}
    L -->|YES| L1[확인 요청]
    L -->|NO| M[라우트 실행]

    M --> N{RouteType?}
    N -->|RAG_INTERNAL| O[RAG 검색]
    N -->|BACKEND_API| P[Backend 조회]
    N -->|MIXED| Q[RAG + Backend]
    N -->|LLM_ONLY| R[LLM 직접 호출]
    N -->|SYSTEM_HELP| S[시스템 도움말]

    O --> O1[Query Expansion]
    O1 --> O2[Milvus 검색]
    O2 --> O3[RRF Fusion]
    O3 --> O4[Quality Gate]
    O4 --> O5{Quality Action?}
    O5 -->|REJECT| O6[INSUFFICIENT 응답]
    O5 -->|PROCEED| T[LLM 프롬프트 구성]

    P --> T
    Q --> T
    R --> T
    S --> T

    T --> U[LLM 호출]
    U --> U1{성공?}
    U1 -->|NO| U2[에러 응답]
    U1 -->|YES| V[Answer Guard]

    V --> V1[Citation Guard]
    V1 --> V2[Statistical Guard]
    V2 --> V3[Korean Output]

    V3 --> W[PII 마스킹 OUTPUT]
    W --> X[응답 조립]
    X --> Y[AI 로그 생성]
    Y --> Z[ChatResponse 반환]

    C1 --> Z
    E1 --> Z
    K1 --> Z
    L1 --> Z
    O6 --> Z
    U2 --> Z

    style A fill:#e3f2fd
    style Z fill:#c8e6c9
    style C1 fill:#ffcdd2
    style E1 fill:#ffcdd2
    style O6 fill:#fff3e0
    style U2 fill:#ffcdd2
```

## 3. RAG 파이프라인 상세

```mermaid
flowchart TD
    A[마스킹된 쿼리] --> B[정규화]
    B --> C{길이 40자 미만?}
    C -->|YES| D[Query Expansion]
    C -->|NO| E[원문 그대로]

    D --> D1[YAML 규칙 로드]
    D1 --> D2{키워드 매칭?}
    D2 -->|YES| D3[동의어+관련어 확장]
    D2 -->|NO| E
    D3 --> F[확장된 쿼리]

    E --> G[원문 쿼리 검색 top_k=5]
    F --> G
    F --> H[확장 쿼리 검색 top_k=5]

    G --> I{결과 0건?}
    I -->|YES| J[2nd-chance top_k=15]
    I -->|NO| K[원문 결과]
    J --> J1{여전히 0건?}
    J1 -->|YES| L[빈 결과]
    J1 -->|NO| K

    K --> M{확장 결과 존재?}
    H --> M
    M -->|NO| N[원문만 사용]
    M -->|YES| O[RRF Fusion]
    O --> O1[score = 1/k+rank]
    O1 --> P[재정렬된 결과]
    N --> P

    L --> Q[sources 빈 배열]
    P --> R[Low-Relevance Gate]
    R --> S[anchor 키워드 매칭]
    S --> T[Quality Gate]
    Q --> T

    T --> U[L2 거리 통계]
    U --> V{min_L2?}
    V -->|1.4 이하| W1[OK - PROCEED]
    V -->|1.4~1.6| W2[LOW - WARNING]
    V -->|1.6 초과| W3[INSUFFICIENT - REJECT]

    W1 --> X[RagRetrievalResult]
    W2 --> X
    W3 --> Y[명확화 응답 생성]

    style D3 fill:#e8f5e9
    style O fill:#e3f2fd
    style W1 fill:#c8e6c9
    style W2 fill:#fff3e0
    style W3 fill:#ffcdd2
```

## 6. PII 마스킹 플로우

```mermaid
flowchart TD
    subgraph INPUT[INPUT 단계]
        A[사용자 질문 원문] --> B[PII 서비스 호출]
        B --> C{서비스 정상?}
        C -->|YES| D[PII 검출 마스킹]
        C -->|NO| E[Fail-Closed 발동]
        D --> F[마스킹된 쿼리]
        E --> G[안전 메시지 반환]
    end

    subgraph OUTPUT[OUTPUT 단계]
        H[LLM 응답 원문] --> I[PII 서비스 호출]
        I --> J{서비스 정상?}
        J -->|YES| K[PII 검출 마스킹]
        J -->|NO| L[Fail-Closed 발동]
        K --> M[마스킹된 응답]
        L --> N[안전 메시지 반환]
    end

    subgraph LOG[LOG 단계]
        O[질문 + 응답] --> P[PII 마스킹]
        P --> Q[Elasticsearch 저장]
    end

    subgraph PRIVACY[Privacy Query Gate]
        R[마스킹된 쿼리] --> S[조합 규칙 체크]
        S --> T{총점 6점 이상?}
        T -->|YES| U[BLOCK 차단]
        T -->|NO| V[ALLOW 허용]
    end

    style E fill:#ffcdd2
    style G fill:#ffcdd2
    style L fill:#ffcdd2
    style N fill:#ffcdd2
    style U fill:#ffcdd2
    style F fill:#c8e6c9
    style M fill:#c8e6c9
    style V fill:#c8e6c9
```
