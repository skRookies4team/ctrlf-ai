## 1. 개요

CTRL-F AI 채팅 시스템은 사용자의 질문을 받아 RAG(Retrieval-Augmented Generation) 기반으로 답변을 생성하는 파이프라인입니다.

### 주요 특징

- **16단계 파이프라인**: PII 마스킹 → Intent 분류 → RAG 검색 → LLM 생성 → 검증
- **역할 기반 라우팅**: EMPLOYEE, ADMIN, INCIDENT_MANAGER별 다른 처리 경로
- **3단계 PII 마스킹**: INPUT, OUTPUT, LOG 단계별 개인정보 보호
- **Phase 39 가드레일**: 민원 Fast Path, Answerability Gate, Citation 검증

### API 엔드포인트

| 엔드포인트 | 메서드 | 설명 |
|-----------|--------|------|
| `/ai/chat/messages` | POST | 동기 채팅 응답 |
| `/ai/chat/stream` | POST | 스트리밍 채팅 응답 (NDJSON) |
